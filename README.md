# Repository Documentation Additions

This folder contains a workbook about a possible Kubernetes Prow / GitHub Actions open-source contribution.

> **Important repository-fit note:** Your current repository is `AWS-VPC-Peering-Project`. The Kubernetes contribution is a separate topic from AWS VPC peering. To keep your portfolio clear, the recommended option is to store this workbook in a separate Kubernetes contribution repository. If you still want it in this repository, this folder keeps it clearly separated under `docs/`.

## Contents

- `Kubernetes_GitHub_Actions_Contribution_Workbook.pdf` — project brief, issue investigation steps, proposed implementation workflow, validation checklist, troubleshooting, PR outline, and interview preparation.

## Before making a contribution

The workbook discusses Kubernetes Prow issue [#389](https://github.com/kubernetes-sigs/prow/issues/389) and linked pull requests [#432](https://github.com/kubernetes-sigs/prow/pull/432) and [#392](https://github.com/kubernetes-sigs/prow/pull/392).

Check their current status before coding. The workbook is a plan and learning guide; it does not claim that a code change has been implemented, tested, or merged.
